# voice-to-text

Chrome extension - hold **Space** to dictate into any text field. Language: English + 繁體中文.

<p align="center">
  <img src="popup_screenshot.png" alt="Spacevoice popup" width="220">
</p>

## Install

1. Open `chrome://extensions`, enable **Developer mode**.
2. **Load unpacked** → select this folder.

## Use

- Click into a text field, hold `Space`, speak, release.
- In Google Docs, use `Shift`+`Space` instead.
- Switch language from the popup.
